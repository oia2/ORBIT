ORBIT / Foundation v0.1

Спокойная система для ясных решений.

Lightweight design system фиксирует уже найденный язык продукта: графитовые поверхности, индустриальную типографику, точные данные и один живой motion-акцент.

01 / Visual language

Тихая технологичность без стерильности

ORBIT выглядит как личный инструмент, а не корпоративная панель контроля. Интерфейс поддерживает ритм человека: данные конкретны, оценки не агрессивны, атмосфера остаётся собранной.

ГРАФИТ

70–90% экрана занимают тёмные нейтральные поверхности. Разница уровней строится тоном и границей.

ТИПОГРАФИКА

Широкие индустриальные заголовки задают характер. Основной текст остаётся нейтральным и спокойным.

ДАННЫЕ

Числа всегда имеют единицы, период и объяснение. Формула результата доступна рядом с показателем.

ОДИН ЖЕСТ

На экране допускается один выразительный приём: орбитальное поле вокруг главного показателя.

04 / Analytics

Данные читаются до декора

Dashboard строится от общего результата к причинам и действиям. Не использовать одинаковые KPI-карточки без приоритета: главный показатель крупный, вторичные метрики компактны, подробности раскрываются ниже.

Правила графиков. Показывать единицы и период; кодировать значение заливкой, а не контуром; success ≥70, warning 50–69, danger <50; не смешивать семантический статус с brand accent; объяснять состав агрегированного результата.

Iconography

Тонкая моно-линия

Иконки служат действию или состоянию, а не украшают каждый заголовок. Размеры 16/20/24 px, stroke 1.6–1.8 px, currentColor, без emoji и разноцветных наборов.

Действие

Добавление, создание, разворачивание. Подпись обязательна в незнакомом контексте.

Статус

Завершение и подтверждение. Семантический цвет появляется только после действия.

Навигация

Переход между уровнями. Не дублировать стрелкой каждый текстовый линк.

05 / Motion

Один живой акцент на экран

Декоративное поле связывается только с главным агрегированным показателем. Оно создаёт атмосферу и реакцию, но не кодирует данные, которые нельзя прочитать без анимации.

06 / Usage

Как сохранять характер системы

Масштабирование строится добавлением понятных продуктовых модулей — календаря, проектов, месячного обзора — без новых палитр и декоративных метафор.

Делать

  • Начинать экран с периода, результата или следующего действия.
  • Показывать причину агрегированного показателя.
  • Использовать воздух между группами, а не внутри каждой строки.
  • Держать одну главную цифру и один motion-акцент.
  • Перестраивать мобильный layout, а не сжимать desktop.

Не делать

  • Не превращать интерфейс в сетку одинаковых KPI-карточек.
  • Не использовать accent как универсальный цвет ссылок и кнопок.
  • Не наказывать пользователя цветом за низкий ресурс.
  • Не добавлять тени каждой поверхности.
  • Не запускать несколько фоновых анимаций одновременно.
