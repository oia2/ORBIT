# ORBIT — визуальная система личного планера

Полная интерактивная спецификация: `orbit-design-system.html`. Канонические reusable-токены: `orbit-tokens.css`.

Система строится на почти чёрном графитовом поле из референсов, холодном электрическом акценте и типографическом motion-слое, который оживляет общий прогресс без буквального повторения исходных композиций.

## Токены

```css
:root {
  --bg: oklch(0.17 0.008 255);
  --surface: oklch(0.22 0.012 255);

  --border: oklch(0.38 0.014 255 / 0.62);

  --font-mono: "Cascadia Code", "IBM Plex Mono", Consolas, monospace;
}
```

## Правила позы

- Плотные данные собраны в ясные горизонтальные ритмы, а не в сетку одинаковых KPI-карточек.
- Главный показатель недели живёт внутри генеративного символьного поля; motion поддерживает прогресс, но не перекрывает цифры.
- Акцент используется только для текущего контекста и главного действия; семантические цвета остаются локальными.
- Заголовки широкие и индустриальные, основной текст нейтральный, числовые данные и временные метки — моноширинные.
- Поверхности отличаются тональными ступенями и тонкими границами; декоративных градиентных заливок нет.
